### 7.100 ★★★ 第 117 条（本轮）：落点分派器主段 `0x4198b9`（2,924 B）最重的一支 —— 查出 **`GOD_BLOCKS_PURCHASE = 0xc` 就是「土地公」**（复刻有一处**过时注释**）

工作单里 `0x4198b9`（2,924 B，落点分派器主段）与 `0x41a3be`（1,384 B）是「写规则字段」
候选里最重的两支。本轮把 `0x4198b9` 的**买地／升级两支**与复刻逐条对读。

#### (1) 自有地那一支（`0x4198b9`..`0x419a5c`）—— 复刻逐条一致

| 原版 | 复刻 |
|---|---|
| `bx = word[esp+0xf0]`（格值）；`0` ⇒ 尾声 | `landIndexAtPlayer` 拿不到就结束 |
| `0x7d0 < bx < 0xfa0` ⇒ 地块记录 = `[0x498e84] + (bx−2000)*0x34` | `landIndexAtPlayer` |
| `[记录+0x19]`（owner，1 基）`== [0x49910c]+1` ⇒ 自有地 | `landingOnLand → 'own'` |
| `[记录+0x1a] >= 5` ⇒ 尾声（满级）| `canUpgrade` 的 `maxLevel` |
| `[记录+0x18] != 0` ⇒ 尾声（不是住宅 = 連鎖店）| `canUpgrade` 的 `chainStore`（`type !== LAND_TYPE_HOUSE`）|
| `[player 当前+0x37] != 0` ⇒ 尾声（梦游）| `canUpgrade` 的 `sleepWalking` |
| 升级费 = `word[记录+0x1e]（房价） × [0x4990e8]（物价）` | `upgradeCost = land.housePrice * priceIndex` |
| 费 > 现金 ⇒ `您的現金不足！`（`0x41a52`）| `notEnoughCash` |
| 成功：`扣现金` → `inc byte [记录+0x1a]`（**等级 +1**）→ `0x41d476(0,0,1)` 重绘 → 音效 `0x4823da` → 满 5 级再 `player_say(角色表事件) + 0x40b0cd`（FLIC），否则 `0x44f627` | `reduce.ts` 的 `upgrade` 分支 |

#### (2) ★★ 无主地那一支（`0x41a013`..）的四道闸，与一处**过时注释**的订正

```asm
; @source 0x0041a013（无主地：能不能买）
0041a01a  cmp byte [eax + 0x496b9f], 0 / jne 结束   ; ① +0x37 梦游（`0x496b9f` = +0x37）
0041a027  cmp byte [eax + 0x496ba7], 0xc / je 结束  ; ② +0x3f 神明 == 12
0041a034  ...
0041a03f  imul edx, ecx        ; edx = word[记录+0x1e](房价) × ecx(等级)
0041a044  mov  cx, word[记录+0x1c]  ; 地价
0041a048  add  edx, ecx        ; ★ 价 = 房价×等级 + 地价
0041a050  imul ebp, edx        ; × 物价
0041a053  cmp ebp, [eax+0x496b84] / jg 您的現金不足！ ; ③ 现金
```

复刻的 `canPurchase` **四道闸的顺序逐条相同**（`alreadyOwned` → `sleepWalking`
→ `godBlocked` → `notEnoughCash`），价格也对
（`landPurchasePrice = (landPrice + housePrice × level) × priceIndex`）。

★ **但 `land.ts` 里那条注释是过时的**：

```
// ⚠️ 取值 12 **未见于** rich4-re/docs 的记载（文档只列了 1/2/5/6）。
//    语义待确认（DEVELOPMENT_PLAN.md Q3 相关），此处保留原始数值。
```

而 `docs/systems/gods.md` **早就有 id 12 的完整一行**：

| id | 名字 | 修正 | 行为 |
|---|---|---|---|
| **12** | **土地公** | −500 / 0 / 0 | **無立即效果；落腳時強佔土地**（台词 `0x46344e`「呵∼呵，有土斯有財…有我在，你想要多少土地就有多少」）|

⇒ 这道闸的语义是：**土地公在落脚时已经把地占走了，玩家不需要（也不该）再掏钱买**
—— 与「落腳時強佔」是同一件机制的两面。

**本轮改动**：① `land.ts` 的注释订正（写明 id 12 = 土地公 + 原文出处）；
② `land.test.ts` +1 例把「四道闸的顺序」钉住（同时断言
`GOD_BLOCKS_PURCHASE === 12`），并给原来那条「特定神明状态」的用例补上身份说明。
