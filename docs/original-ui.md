## 2. 存讀檔屏

- 第一行是 AUTO 存档 ✓（这一条先前就对）。
- **每一行会把参与这一局的全部角色头像都摆出来**，还有时间。

已回汇编核实，整行的构成是（VA 0x00403f4b 起）：

```asm
00403f55  edi = 72*slot + 0x18                       ; 行 y
00403f59  draw(资源520 图10, 0x81, edi)               ; 左格：粉色底板，x = 129
00403f78  if (slot == 0)
00403f82    draw("AUTO", 0xa5, edi + 0x0f, 2)        ; ★ 只有 0 号槽写 AUTO
00403fb3  draw("%d" 年,   0xa5, edi + 0x24, 2)
00403ffc  draw("%d/%d" 月日, 0xa5, edi + 0x39, 2)
00404016  图号 = [0x48a33c] + 2 + [0x48a330]*4        ; = 2 + globalMapId
00404011  draw(那张图, 0xd1, edi)                     ; 中格：地圖縮圖，x = 209
0040404f  esi = 0x121                                 ; ★ 头像起点 x = 289
00404056  for (i = 0; i < 存档头里的玩家数; i++) {
00404065    dl = 玩家[i].character
00404088    draw(资源2 图[character], esi, edi)        ; 72×72 头像
00404091    esi += 0x48                                ; 步进 72
          }
```

即：**粉色底板（写年月日）｜ 地圖縮圖 ｜ 参与角色的头像一排**。
存档头也顺带解出来了：`4 字节标识 0x26 ｜ 4 字节日期(日|月<<8|年<<16) ｜
2 字节 gameMap ｜ 2 字节 gameStage ｜ 4 字节玩家数 ｜ 4 × 0x68 玩家结构`。

**已按此改正。**
