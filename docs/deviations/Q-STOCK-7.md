> `docs/deviations/Q-STOCK-6.md`），本轮顺延取 **Q-STOCK-7**。
>
> 本文件登记：① 逐列回 exe 取证的结论（含 VA）；② 落地在哪些文件；
> ③ 本轮**没解出 / 有意没动**的几处。
>
> 起因 = `Q-STOCK-6.md` 的残留项 **e**：`stock-screen.ts` 的 `stockRowsFrom`
> 对未上市股票同样读了 1 基企业表的第 0 格（上一轮详情卡 `stock-detail.ts` 刚修过同类）。

## 〇、判据（复用上一轮已确证的那条，没有另发明）

股票记录 `_stocks_on_map`（0x496980，每支 36 字节）的 **`+4` 是 1 基企业序号，
`0` = 这支股票没有上市公司**：

```
0x00429a99  mov  eax, esi / shl 3 / add esi / shl 2      ; i*36
0x00429aa0  cmp  word [eax + 0x496984], 0
0x00429aa9  je   0x429abb                                ; 0 → 白色字
```

同一个 `cmp word [.. + 0x496984], 0` 在股市这两页里一共出现 **5 次**，每次都只
决定「换字色 / 跳过某格」，**没有一次是"换一列数字"**。下面逐列过。

## 一、逐列取证

### 1. 行情页（资源 75 的图 0）—— `fcn_004297f7`，参数 `page == 0`

入口 `0x004298a0` `mov esi,[esp+0x9c] / test esi,esi / jne 0x429b87`，
`page == 0` 走 `0x004298af` `mov ebp,0x60` → `0x004298b4 jmp 0x429b6c`。

| 列 | 值从哪里来（VA）| 未上市时 |
|---|---|---|
| 股票名稱 | 记录 `+0`（`0x0042b75e` 的 `push 0x4c`，画在 `surface+0xc`）| **照画** |
| 成交價 | 记录 `+0x14`（读 `0x00429964`–`0x00429971`，画 x=0xe1 @`0x00429984`）| **照画** |
| 漲跌 | `+0x14 − +0x10`（读 `0x004299f1`–`0x004299f7`，画 x=0x131 @`0x00429a2e`）| **照画** |
| 交易量 | `word +0xa`（读 `0x00429a68`，画 x=0x191 @`0x00429a91`）；`0x00429a36` `cmp byte [ebx+0x496986],0 / je 0x429a66`，`+6 != 0` 时走 `0x00429a57`–`0x00429a64` 改画「暫停交易」（串 0x46400f、x=0x170）| **照画** |
| 持有股數 | **玩家**持股 `_rich4_player_stocks[current][i]`（读 `0x00429aea`；`0x00429af0` `test ecx,ecx / je 0x429b5f`；画 x=0x1f8 @`0x00429b11`）| **照画**（只有"自己没持股"才不画，与 comm 无关）|
| 平均成本 | 同一条记录的 `+4` float（读 `0x00429b29`；`0x00429b36` `sprintf("%.2f")` @0x463f64；画 x=0x261 @`0x00429b57`）| **照画**（同上）|
| ★ 唯一用 `+4` 的地方 | `0x00429aa0` 的 `cmp … / je 0x429abb` → **定「持有股數／平均成本」两列的字色**：上市青 `0xf0f0`（`0x00429ab4`）、未上市白 `0xf0f0f0`（`0x00429ac4`）| **只有颜色变** |

⇒ **行情页没有任何一列读企业表**；`+4` 在这里只决定字色。已上市/未上市是同一批数字。
（本引擎 `shares` / `cost` 取的是 `state.holdings[player][i]`，`hc` 取 `listed` —— 本来就对，未动。）

### 2. 持股页（图 1）—— `fcn_004297f7`，参数 `page != 0`

入口 `0x004298a0` `jne 0x429b87` → `xor esi,esi / mov ebp,0x60 / jmp 0x429ccd`。

行头 `0x00429ccd`–`0x00429cf6` 会先按 `+4` 算出「企业记录指针」存进 `[esp+0x84]`
（`0x00429cd4` `mov ax,word [eax*4+0x496984]`、`imul edx,eax,0x34`、`add eax,[0x498e7c]`）——
★ 未上市时它就是表首（第 0 格）地址，但**下面两道闸让它永远不被解引用**。

| 列 | 值从哪里来（VA）| 未上市（`+4 == 0`）时 |
|---|---|---|
| 股票名稱 | 记录 `+0`（`0x0042b786` 的 `push 0x47`，画在 `surface+0x18`）| **照画**（白字：`0x0042b7b0` `cmp … / je 0x42b7d5` 给 `0xf0f0f0`）|
| 各玩家持股 | **玩家**持股 `_rich4_player_stocks[p][i]`（`0x00429bb7` 读、`0x00429c24` 起画，x=edi 从 0xc0 步长 0x50）| **照画**（每格都画）；字色白：`0x00429d0f` `cmp word [eax+0x496984],0 / je 0x429b93` 给 `0xf0f0f0`，否则青 `0xf0f0` |
| ★ 董事長蓝框 | `企业 +0x18`（`0x00429be7` 读、`0x00429bf1` 起 `fill_rect` + 换 `0xf0f000` 字）| **整格跳过**：`0x00429bd3` `cmp word [eax*4+0x496984],0 / je 0x00429c24` —— 连那个字节都不读，蓝框与黄字都不出现 |
| ★ 保留股份 | `企业 +0x30`（`0x00429c66` 取指针 / `0x00429c6d` `mov ecx,[eax+0x30]`，画 x=0x208 @`0x00429c8d`）| **整格不画** |
| ★ 累積盈餘 | `企业 +0x28`（`0x00429c95` / `0x00429c9c` `mov ebx,[eax+0x28]`，画 x=0x261 @`0x00429cbc`）| **整格不画** |

两道闸的落点：

```asm
; 玩家循环跑完（ebx >= num_players）后  @0x00429d03 / 0x00429d09 jge 0x429c40
00429c40  cmp  word [eax + 0x496984], 0     ; ★ +4 == 0 ?
00429c48  je   0x429d30                     ; → 跳过「保留股份 / 累積盈餘」两格
00429c4e  push 1/3/0x101010/0xf0f0          ; 上市 → 青字
00429c66  mov  eax,[esp+0x84] / mov ecx,[eax+0x30]   ; 保留股份   → draw_text x=0x208
00429c95  mov  eax,[esp+0x84] / mov ebx,[eax+0x28]   ; 累積盈餘   → draw_text x=0x261
00429cc1  add esp,0x14 / inc esi / add ebp,0x20 / cmp esi,0xc / jge 0x429d4a
; —— 跳过那两格的那条：
00429d30  push 1/3/0x101010/0xf0f0f0        ; 只建一枚**白字**字体（下一个玩家的字色）
00429d45  jmp  0x429cc1                     ; ★ 直接进行尾，两次 draw_text 全不执行
```

⇒ **未上市的行在持股页上：名字有、各玩家持股数有（白字）、董事長蓝框没有、
`保留股份` 与 `累積盈餘` 两格是空白** —— 不是 `0`，更不是企业表第 0 格的数字。

## 三、本轮**没解出 / 有意没动**的

### Q-STOCK-7-a　持股页各玩家持股数「0 也画」—— 本引擎把 0 跳过了（★ 顺带发现，未动）

- **取证**：`0x00429cf9`–`0x00429c24` 那一圈**没有**任何零值判断 ——
  读 `_rich4_player_stocks[p][i]`（`0x00429bb7`）→ `_rich4_num_to_currency_string`
  （`0x452793`）→ 无条件 `draw_text`（`0x00429c24` 起）。而 `num_to_currency_string`
  对 0 会写出 `"0"`：`0x4527a7` 先 `itoa`（`0x457d61`）、`0x4527b7` `strlen`（`0x45825d`），
  长度 1 > 0 就进循环把那个字符写进缓冲（`0x4527f3`）。⇒ **原版每个玩家的格子都会打出数字，
  没持股就是 `0`**。
- **本引擎**：`drawStockScreen` 图 1 那支写的是 `if (n === 0) continue;`
  （文件头也写着「0 的不画」）⇒ 未持股的格是**空白**。这是一处**实打实的保真差**。
- **为什么本轮没动**：它**不是** `+4`/企业序号那条线上的 bug（值取自玩家持股，
  与 comm 只共享"字色"这一处），本轮任务边界是「所有用 `+4` 的列」；
  改它要连带决定「4 个玩家 × 12 行全是 `0`」的观感，属于另一件事。
  本轮**只登记、代码未动**，留给下一轮单独取证/目视核对后再改。
- **处置**：✅ **2026-09-16 已改** —— `stock-screen.ts:770` 那一圈的零值跳过删掉了，
  现在每格都画（没持股写 `0`），注释里带着 `loc_00429cf9`..`0x00429c24` 与 `0x452793` 的出处；
  用例 `stock-screen.test.ts:411`「★ 没持股画成 `0`，不是留空（原版那一圈没有零值判断）」。

### Q-STOCK-7-b　未上市时 `[esp+0x84]` 仍算了企业指针（无观测影响，照抄现状）

- **取证**：`0x00429cd4`–`0x00429cf6` 无条件按 `+4` 算指针并存入 `[esp+0x84]`，
  未上市时得到的是表首（第 0 格）地址。
- **结论**：该槽位只在 `0x00429be0`（董事長）与 `0x00429c66 / 0x00429c95`（两格数字）
  被读，而这三处都在 `+4 != 0` 的闸**之后** ⇒ **从不被解引用**，无观测影响。
- **处置**：**有意不动**（本引擎用 `listed ? … : null/0` 表达同一语义；
  复刻"算了个不用的指针"没有意义也不可观测）。

### Q-STOCK-7-c　行情页 `page == 0` 时 `esi` 既是"页号"又是"行号起点"

- **取证**：`0x004298a0` 把参数读进 `esi`，`0x004298a7` `test esi,esi` 当页号用；
  `page == 0` 不再清零，`0x004298b4` 直接 `jmp 0x429b6c` 让同一枚 `esi` 从 0 开始当行号
  （`page != 0` 那条在 `0x00429b8a` 显式 `xor esi,esi`）。
  这只在"页号恰好等于行号起点 0"时成立。
- **结论**：**原版的巧合式省指令**，语义上两件事互不相干；本引擎函数参数是 `page`、
  循环变量另起，等价。**不改**（登记只为说明这里不是漏读）。
