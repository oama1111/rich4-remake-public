# Q-HOVER-1 偏离登记 —— 点棋盘上的企业／景物弹出的「名牌浮标」

> 需求方原话：「**点击地图上的企业和景物应该有个文字浮标出来说明名字（如果是企业有董事长的
> 话还会把董事长名字一起展示出来）这个你在汇编里看下怎么实现的不要自己瞎搞**」。
>
> **原版确实有这套实现，已全部取证并 1:1 落地。** 本文件先给判据（全部带 VA），
> 再列没解出／有意不同的地方。任务是「找到原版那一套」，所以**没有自创 tooltip**。

## 一、触发条件：不是悬停，是**按住左键**

棋盘窗口过程是 `fcn_00417e26`（VA 0x00417e26）。它的分派：

| 消息 | 去处 | 干什么 |
|---|---|---|
| `0x201` / `0x203`（LBUTTONDOWN / DBLCLK）| `loc_00418151` → … → `loc_004186a7` | **画名牌** |
| `0x200`（MOUSEMOVE）| `loc_00418910` → `loc_00418b63` | **擦名牌**（只擦不画）|
| `0x202`（LBUTTONUP）| `loc_004186cb` → `loc_00418878` | **擦名牌** |

```asm
; 0x201 那一支落到这里（loc_00418670）
00418670  cmp esi, 0x1b8          ; x < 440 → 棋盘那一栏
00418674  jge loc_004186a7
0041867a  cmp edx, 0x28           ; y > 40 → 工具栏之下
0041867e  jge loc_004186a7
…                                  ; （否则是顶部工具栏的悬停记账）
loc_004186a7:
004186a7  cmp esi, 0x1b8
004186ab  jge loc_00418c30
004186b1  cmp edx, 0x28
004186b5  jle loc_00418c30
004186bb  push edx
004186bc  push esi
004186bd  call fcn_00417559        ; ★ 画浮标 f(x, y)
```

```asm
; 擦除（0x200 与 0x202 都调同一个）
loc_00418b63:
00418b63  cmp dword [0x475270], 0  ; 浮标钉住了吗
00418b6a  je  loc_00418c30
00418b6c  call fcn_00417c67        ; 把先前存的底图贴回去 = 擦掉，并把钉子清 0
```

**结论：这块名牌只在「按住左键」期间挂在屏幕上** —— 按下出现，抬手或鼠标一动就没。
（所以原版是「点击并按住看名字」，不是 hover tooltip。）
`fcn_00417559` 内部命中失败时（`loc_00417c5f`）**连音都不放**。

## 二、框的样子

`fcn_00417559`（VA 0x00417559）的骨架：

```asm
00417560  edx = y − 0x28                        ; 实例表用的是**棋盘局部** y
00417571  call 0x40a9d7(x, y−0x28)              ; _rich4_get_instance_from_position
0041757d..0041759a  编号合法性与区间筛选（见第四节）
004175c4  play_sound_effect(0x482322, 0)        ; 音效 1 = 标题那颗 TITLE_CLICK
004175dd  ebp = (word[0x48bad8+0xe] <= y) ? 1 : 0        ; bit0：框往上放
004175f9  if (x > 0x1b8 − word[0x48bad8+0xc]) ebp += 2   ; bit1：框往左放
00417611  eax = 189/2 + 9 = 103
00417637 / 0041766f / 0041769f / 004176cd       ; 四个象限各自的框矩形与文字基准
004176fe  [0x48bdf4] = 框 x；[0x48bdf0] = 框 y（+0x28 回屏幕）
00417713  esi = x ± 103                          ; 文字横坐标
00417717  edi = y + 0x28；ebx = y_screen + {0x2a | −0x60}
00417722  create_font(0x10, 0xf0f0f0, 0x101010, 3, 1)   ; 16 号、白字黑边
00417780  fcn_00451a97(屏幕图, [0x48bde0], x0, y0, w, h) ; ★ 把框底下那块底图存起来
004177ab  fcn_00456418([0x48a08c], 第 ebp 张图, x, y)   ; ★ 贴名板（非零像素 = 透明）
…
00417c4d  [0x475270] = 1                                 ; 钉住，供 0x200/0x202 擦
```

- **底图资源**：`[0x48bad8] = read_mkf(Data.mkf, 0x205, 0, 0)`（VA 0x0040808f）
  = **`Data.mkf` 资源 517**；第 `ebp` 张就是 `[0x48bad8] + 0x0c + 12×ebp`
  （精灵表从 `+0x0c` 起、每张 12 字节头）→ **图 0..3**。
- 四张都是 **189×116**，只有「小尾巴」冲的角不同；锚点（资源头 `x/y`，
  见 `assets-clean/manifest.json` 的 `Data/0517_000..003`）：

  | 图 | 锚点 | 尾巴 | 框落在光标 |
  |---|---|---|---|
  | 0 | (0, 0) | 左上 | 右下 |
  | 1 | (0, 116) | 左下 | 右上 |
  | 2 | (189, 0) | 右上 | 左下 |
  | 3 | (189, 116) | 右下 | 左上 |

- **落点算法**（`x/y` 为棋盘局部坐标，y 已减 40）：
  - `bit0 = (y ≥ 116)`、`bit1 = (x > 440 − 189 = 251)`，图号 = `bit0 + bit1`；
  - 框左上 = (光标 − 锚点)；文字基准 = `(x ± 103, y + {0x2a | −0x60})`。
- **字体/对齐**：`create_font(0x10, 0xf0f0f0, 0x101010, 3, 1)` + `draw_text(..., flag 2)`
  —— flag 2 = **正中**（`board-screen.ts` 的 `origText` 已经这么译：center/middle + 3px 描边）。
- **文本块是居中排的**：名板内框（蓝底）实测 (29,33)-(174,104)、中心 y≈68.5；
  往下的框基准 `y+42`、往上的框基准 `y−96`，加上行偏移后单行正好落在 `y+69`、
  三行块中心也在 `y+69` —— 与内框中心吻合。
- **不跟鼠标走**：画一次就钉住（`[0x475270] = 1`），靠存下来的底图擦除；
  原版那个「存底图 + 贴回」在浏览器里不需要，本引擎每帧重画棋盘、浮标只是状态。

## 三、显示什么文本（逐条照分支）

实例编号分区（`loc_004177ed` / `loc_00417942` / `loc_00417ae4` / `loc_00417b4f`）：

| 区间 | 是什么 | 条件 |
|---|---|---|
| `1 .. 0x7cf` | 节点（路面／特殊格）| `< 0x7d0`，且 `node+4` **名字非空**（VA 0x004175b9）|
| `0x7d0 .. 0xf9f` | 地块 | `0x7d0 + 下标` |
| `0xfa0 .. 0x176f` | 設施 | `0xfa0 + 下标` |
| `0x1770 .. 0x1f3f` | 上市企业 | `0x1770 + 下标` |
| `0x1f40 .. 0x270f` | **特殊景觀** | `0x1f40 + 下标`（基址 `[0x498e78]`，步长 0x1c）|
| bit15 置 1 | 玩家棋子／附身神明 | `test byte [esp+0x4d], 0x80` |

各分支画什么（`dy` = 相对文字基准的偏移）：

- **企业**（`loc_00417ae4`，行距 `0x1b`）：
  1. `dy=0` 业主名 —— `mov ebp, dword [eax + 0x496b68]`，玩家结构 **+0 = `const char *name_ptr`**
     （无主时这一行留白）
  2. `dy=0x1b` 企业名 —— `commercial + 0x04`
  3. `dy=0x36` `餘股:%d` —— `commercial + 0x30`（运行时自留股数）
- **景觀**（`loc_00417b63`）：一行，`landscape + 0x04` 的名字，`dy=0x1b`。
  ★ 这一段**没有**空名字检查 —— 名字空的照弹，框里是空的。
- **节点**（`loc_004177c2`）：一行，`node + 0x04` 的名字，`dy=0x1b`。
- **地块**（`loc_004177ed`，行距 `0x12`）：业主名（有主时）→
  `level==0 ? 空地 : (type!=0 ? 連鎖店 : 0x475138[level])` → `0x475164[level]` →
  第三行三选一：无主 = `rentByLevel[level]`；有主+連鎖 = `2000×物價指數` 接 `×連鎖店數`
  （`0x41970f` 数连鎖店）；有主+非連鎖 = **同名地块**过路费之和（`0x419744`）。
- **設施**（`loc_00417942`）：业主名（有主时）→ `level==0` 只画「空  地」；
  否则按 `facility + 0x18`：0 公園一行；1/2 旅館/購物中心三行（類別/等級/`×費率×指數`）；
  3 加油站两行（`×1000`）；4 研究所（類別/等級/开发出来的东西）。
- **玩家棋子**（`loc_00417b7e`）：一行，`dy=0x19`。`id & 0xff != 0` → 尾零个数取玩家号
  （4..7 是 `_rich4_special_player_names` 那四个人物）；否则 `(id & 0x7f00) >> 8`
  取 `objects_info` 的种类 → `_rich4_god_names`。

**「景物」对应哪一段**：地圖数据里 `landscape` 记录自带名字（实测地图 1：
醫院/綠島/沙崙/野柳/基隆港/石門水庫/龜山/台中港/阿里山/玉山/澄清湖/佛光山/高雄造船/墾丁/陽明山/八卦山，
另有 4 条空名字）。特殊格（公園/銀行/監獄/醫院/樂透/魔法屋/新聞/命運/百貨公司/卡片/得點/城市名…）
走的是**节点**那一段。两者都在本次实现里。

## 四、与「查詢」按钮／熱鍵的关系：**不是同一个东西**

熱鍵 16 的名字表里叫「查詢」，但 `rich4_keyboard_hook.asm` 把它映射到工具栏第 6 颗：

```asm
; cfg + 48（= 熱鍵 16）→ push 6 → _rich4_ui_clicking_top_panel(6)
loc_00417dd9:  call _rich4_ui_player_info_view_entry   ; = 個人資產表屏（T-022）
```

工具栏那 11 颗的顺序是 `_rich4_ui_clicking_top_panel` 的跳表 `0x417d39`：
說明/系統/託管/讀取/儲存/地圖/**查詢(=個人資產表)**/道具/卡片/交易/股市。
名牌浮标是棋盘窗口过程自己画的，与那颗钮、与熱鍵、与拾取模式（T-026）都没有共用代码。

## 六、没解出／有意不同的地方

| # | 现象 | 取证 / 原因 | 处置 |
|---|---|---|---|
| 1 | ~~**研究所**（設施 type 4）第三行「开发出来的东西」没画~~ ✅ **已做（Q-TOOL-6）** | 那一行要 `facility + 0x1e`（有没有）与 `+0x1d`（`0x47ff1a` 表下标）| `FacilityInfo` 已补 `researchProject?`/`researchDays?`（解析自 `+0x1d`/`+0x1e`），浮标第三行已画。★ 顺带修正：設施那一支改读 **state** 的归属/等级/种类（模板兜底）—— 地图模板里 `type/level` 恒 0，不这样到不了研究所那一支。取证、拼法与残留见 `docs/deviations/Q-TOOL-6.md` ② |
| 2 | 命中用**最近锚点 + 24px 半径**，不是原版的**逐像素实例表** | 原版 `fcn_00409b18` 把画上去的东西按**每个非透明像素**戳进 `0x474938`（格子 32×32 世界单位），后戳的盖住先戳的；本引擎没有那张表 | 按 `picking.ts` 已有的办法近似；重叠/等距的边界情形可能与原版差一格，登记于此 |
| 3 | 同一像素上**谁赢**的顺序 | 原版：先戳节点、再戳「场所实例」（地块/設施/企业/景觀），棋子与物件最后戳 | 本实现按「棋子/物件 > 建筑 > 节点」的优先级 + 距离复现 |
| 4 | 编号 ≤ 0 时原版会**读越界内存**（`cmp byte [node_ptr + id*40 + 4], 0`）| `004175a0` 起，`id` 为负时算出来的指针在表外 | 实例表里不会出现这种编号；本实现直接当「没有」，不模仿越界读 |
| 5 | 訊息框／整屏盖着棋盘时本实现**不弹名牌** | 原版名牌画在棋盘窗口、訊息框是**另一个顶层窗口**：点在框外那一块仍会弹 | 本引擎的 mousedown 对这些整屏是「先接管、直接 return」，落在这里就不弹；框内框外的区分没有做 |
| 6 | 名牌画在棋盘面上、**訊息框之下** | 原版是两个窗口，名牌在棋盘窗口里 | 同 5：本实现把名牌画在 `dlg === null` 时，訊息框出现时名牌不画 |
| 7 | 原版贴图前后要**藏/显软光标**（`fcn_0040235d` / `fcn_00402250`）| 那是原版自绘光标，浏览器里是系统光标 | 不做 |
| 8 | 原版「钉住」靠 `[0x48bde0]` 存下来的底图贴回 | 浏览器每帧重画 | 改成状态位（`nodeTip`），行为一致（移动/抬手即消失）|
| 9 | 企业第一行是 `player->name_ptr`，不是角色名 | 玩家结构 +0 是 `const char *name_ptr`（`rich4_player_info.h`）| 本引擎没有改名功能，取 `CHARACTERS[character].name`（与 股票/分紅 等屏同一处理）|
