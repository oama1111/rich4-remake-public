## 0. 一句话

整站一道**共享密码**（不是账号系统）：`/login` 一张最朴素的表单 → 一张 HMAC 签名的
HttpOnly cookie → 除 `/login`、`/robots.txt` 外**每一个** HTTP 请求与 **WebSocket 升级**
都要验它。密码与密钥只从环境变量来，缺一个就拒绝启动。

## 1. 环境与跑法

```bash
RICH4_PASSWORD='…' RICH4_COOKIE_SECRET="$(openssl rand -hex 32)" \
  node --experimental-transform-types packages/server/src/cli.ts --web packages/client/dist-web
```

| 项 | 值 |
|---|---|
| 机器 | `MacBookAir10,1`（Apple M1，8 GB） |
| 系统 / Node | macOS `26.6.2` / `v22.22.0` |
| 监听 | `http://127.0.0.1:8787`（缺省只听本机） |

## 2. 拒绝启动（缺变量 / 用错参数）

```
$ RICH4_PASSWORD='secret-do-not-leak-42' node …/cli.ts --web packages/client/dist-web
起不來：缺少環境變數 RICH4_COOKIE_SECRET：簽票用的隨機串（openssl rand -hex 32）
exit=1

$ RICH4_COOKIE_SECRET="$(openssl rand -hex 32)" node …/cli.ts
起不來：缺少環境變數 RICH4_PASSWORD：整站訪問密碼（沒有缺省值，也不許寫進倉庫）
exit=1

$ RICH4_PASSWORD=x RICH4_COOKIE_SECRET="$(openssl rand -hex 32)" node …/cli.ts --host 0.0.0.0 --no-gate
起不來：拒絕啟動：--no-gate 只允許在 127.0.0.1 / localhost 上用（現在的 --host 是「0.0.0.0」）
exit=1
```

★ 第一条的 stderr 里**没有** `secret-do-not-leak-42`（测试里也钉了一条
「报错文本里不许出现密码」）。

| `GET /robots.txt` 无票 | **200**（免检） |

## 4. WebSocket 升级那一道门

同一张 cookie（浏览器对同源升级会自动带上），外加 `Origin` ↔ `Host` 校验：

```
$ curl -i --http1.1 -H 'Connection: Upgrade' -H 'Upgrade: websocket' \
       -H 'Sec-WebSocket-Key: dGhlIHNhbXBsZSBub25jZQ==' -H 'Sec-WebSocket-Version: 13' \
       -H 'Origin: http://127.0.0.1:8787' http://127.0.0.1:8787/ws
HTTP/1.1 401 Unauthorized            # 没带票

$ … -H 'Cookie: rich4_gate=<票>' -H 'Origin: http://127.0.0.1:8787' …/ws
HTTP/1.1 101 Switching Protocols     # 票对了、主机名也对了

$ … -H 'Cookie: rich4_gate=<票>' -H 'Origin: http://evil.example' …/ws
HTTP/1.1 403 Forbidden               # 跨站 Origin

$ … -H 'Cookie: rich4_gate=<票>'（不给 Origin）…/ws
HTTP/1.1 403 Forbidden               # 缺席一律拒（fail closed）
```

★ 「主机名相同、端口不同」在开发时是**正常**的（vite 5173 → 服务器 8787），
所以比的是主机名不是 `host:port` —— 见 `escalations.md` **E-27**。

## 5. 浏览器验收（无头 Chromium）

| 步骤 | 结果 |
|---|---|
| `goto http://localhost:8787/` | 303 → `http://localhost:8787/login` |
| 登录页 | 「大富翁4 重製版」+ 「訪問密碼」输入框 + 「進入」按钮，样式全内联、零外部请求 ✅ |
| 填错密码 → 提交 | 页面出现「密碼錯誤」，`elapsed ≈ 955 ms`（500 ms 延迟 + 进程启动开销） |
| 填对密码 → 提交 | 303 → `/`，**標題畫面**出来了（地球底图 + 五颗钮）✅ |
| `document.cookie` | `''`（**HttpOnly 生效**：脚本读不到票） |
