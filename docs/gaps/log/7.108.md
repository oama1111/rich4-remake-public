#### (1) 两个关键手法（都已成文，后续 WndProc 类测试可直接抄）

**① 手搓帧**（替掉 `emu.call()`）：
```python
eval_block(0x42F7FC, 停址, regs={'esp': 0x53F000}, setup=…)
#   [ESP] = 哨兵返回地址；[ESP+4/8/c/10] = hwnd/msg/wParam/lParam
```
`call()` 的参数基址由它的压栈序列定，而 WndProc 序言 `push×4 / sub esp,0x5c`
按 **`[esp+0x70]`** 读第一个实参 ⇒ **两者差 0x2c**（第 123 条定位）。
换手搓帧后 `0x104` 的 ESP 漂移**消失**。

**② 停址试两次**：`0x42FDB6`（状态 5「画公库金额」入口）能让**状态链走完**；
而状态 0/4/5 与 `0x201`/`0x205`/`0x405` 那些路径**不经过**它
⇒ 会跑过 `ret 0x10` 而失败，此时退回 `0x42F92D`。
