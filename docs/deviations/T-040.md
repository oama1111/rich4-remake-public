回头逐字节复核后确认**根因是我先前的两处读错**：

| 先前（错） | 现在（对） | 依据 |
|---|---|---|
| 項目图标 = `Panel.mkf` 11 图 **1..5** | 图 **10..14** | `fcn_0044101d` 里 `ebp = read_mkf(panel, 0xb)`（VA 0x00441040 配 `[0x48a05c]`、0x00441051 `mov ebp,eax`），记录指针 = `ebp + 12 + 12*(k+10)`。用 1..5 时第 0 格画出来的是那张 **412×180 的粉格底图**，整屏崩掉 |

## D-040-2（**已销案**）命中判据 `ebx`/`eax` 谁是 x —— 是 **x**，五格横排

@source `loc_00440377`：

```asm
00440379  mov bx, dx / shr eax, 0x10  ; ebx = 低16位、eax = 高16位
004403ab  cmp ebx, 0x23   / jl 不认    ; x
004403b4  cmp ebx, 0x196  / jg 不认
004403c0  cmp eax, 0x129  / jl 不认    ; y
004403cb  cmp eax, 0x15f  / jg 不认
004403d6  lea edx, [ebx - 0x23]
004403e3  idiv 0x4c                    ; 格号 = (x − 35) / 76
```

先前我读成 `ebx` = y，理由是「图标 y = 0x2c + 76k 是竖排」——
那是**把 `fcn_004562a5(dest, img, a, b)` 的 a/b 当成了 (y, x)**。五格横排才是对的，
四条独立证据互相咬合：

1. **图标是横排的**：`fcn_004562a5(内层表面, 图, x=0x21+esi, y=0x2c)`，`esi = 0xf + 0x4c·k`
   → 五格在 `x = 0x30 + 0x4c·k`、**y 恒 0x2c**。内层表面只有 **400×89**
   （= Data517 图 7 的尺寸）：竖排放不下 5 格（`0x2c + 4×0x4c = 0x15c > 89`），
   横排正好（`0x30 + 4×0x4c = 0x160`，+36 = 0x184 < 400）。
2. **去色块就是命中框**：去色块 `(0x0f+0x4c·k, 0x11)` 66×54 → 屏幕 `(35+76k, 297)`，
   命中框正是 `x∈[35,406]`、`y∈[297,351]` —— **两边逐像素重合**（单测有一条专门钉它）。
3. **黄框在格子外一圈**：外框 `(0x20+0x4c·r, 0x126)` 71×59 = `(32+76r, 294)`，
   内框 `(33+76r, 295)` 69×57 —— 正好把 `(35+76r, 297)` 的 66×54 套住。
4. **y 带只有 54px 高**（= 0x36 = 去色块的高）。若按 y 取行则只有第 0 格可点，
   与「5 个格子 5 个项目」矛盾。

**处置**：`hitResearch` 用 `row = floor((x − 35) / 76)`，`y` 只判在不在 `[297,351]` 里。
单测覆盖「每格四角各命中自己 / 左右越界一像素不认 / 上下越界一像素不认 / 换 y 不改格号」。

## A-040-3（假设 · 已按下述落地）去色块用 canvas 的 `saturation` 混合

@source `fcn_004553fe`（VA 0x004553fe）逐像素调 `[pixel_fmt*4 + 0x485968]`
那四支例程；555 那支（0x00455442）是
`L = (r + g + b + 0x10) >> 2`，再把 `(L,L,L)` 写回 —— **纯灰度**，且**跳过 0 像素**
（`or ax,ax / je` 不动透明处）。原版是在已经画好的位图上就地改；本引擎每帧重画，
所以用 `globalCompositeOperation = 'saturation'` + 中性灰填一块**等价地**变灰。

两者在「纯灰度」这一点上等价，但不是逐像素相同（原版舍入是 `(r+g+b+0x10)>>2`，
canvas 走的是另一套浮点公式，误差 ≤ 1 个 5 位分量）。肉眼不可辨，登记备查。

★ 顺序：原版是**先画图标、再去色**（blit 在 `fcn_004553fe` 之前，
0x004410bb → 0x004410da），所以**画出来的图标是灰的**；悬停只靠黄框 + 板子里的名字，
**没有彩色高亮**。本模块照这个顺序画。
