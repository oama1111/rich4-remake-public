#### (2) ★★ 三条工具边界（已进 `rich4-spec/docs/verification.md` 顶部）

1. **`workdir` 参数 / 含中文的绝对路径会让 harness 起不来进程**
   （`spawn sandbox-exec ENOENT`）。→ 用 **`cd <相对路径> && …`**。
   ★ 这一条曾让本会话**连续四轮**误以为「沙箱坏了」。
2. **原版 `memmove`（`0x456de8`）的 `push es` 在 Unicorn 上报 `UC_ERR_WRITE_UNMAPPED 0xfeb4`**
   → 凡**经它**移牌的路径都跑不了（如 `0x441343` 的「满手弃一张」左移）。
3. **`0x4318f2` 的 `mov cl,[ecx+edi+0x19]` 之后接 `and ecx,0xff`，而 `CL` 与基址 `ECX` 同体**
   → 魔法屋 idx 1/2 的**归属判据不可信**（但读集合「记录 1..num_lands」是稳定的，见 §7.127(4d)）。
