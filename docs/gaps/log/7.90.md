### 7.90 ★★ 第 107 条（本轮）：**补上「卡牌使用者台词」整条链路**（数据 + core 提示 + 客户端通道）

§7.89(2) 查出的缺口（用卡时角色**一个字都不说、语音也不响**）本轮落地。

#### (1) 数据：`@rich4/data` 新增 `card-lines.ts`（12×30 = 360 条）

| 项 | 值 |
|---|---|
| 表 | `0x48123a`，行距 360（90 槽），本模块取槽 0..29 |
| 槽号 | 第 `card` 张卡读槽 `card-1` |
| 语音号 | `#NNNN = 426 + 52×角色 + (卡号-1)`（360 条无例外）|
| 金貝貝（角色 11）| 整列 `#NNNN@DD`：**既播语音也画表情图**（不是二选一）|
| 生成 | `tools/gen-card-lines.py`（`--ts` 直出表字面量）|
| 校验 | `packages/data/src/card-lines.test.ts` 8 例：**360 条逐条与 exe 指针表比对**（文本 + 表情码 + 语音号公式）|

★ **解码器踩坑**：角色 6 的卡 15/16（`#0752晚安∼` / `#0753做個好夢吧∼`）在原版里以
Big5 **用户造字区**双字节 `\x9d\xdd` 结尾。Python 的 `big5` codec **直接拒收**这一段
（给 U+FFFD），而 WHATWG 表（浏览器 / Node 的 `TextDecoder('big5')`，也就是本仓库既定的
解码器）把它解成 **PUA `U+ECBF`** —— 两者不等，全量比对必红。
⇒ **生成脚本改成请 node 解码**（把 360 条原始字节一次交给 `TextDecoder`），
与运行时逐字节一致。这两条已在测试里钉死。

#### (2) core：新增纯表现提示 `GameState.lastCardPlay`

为什么必须由 core 给：原版那句 `player_say(出牌者, flag, 卡牌台词表[角色][卡号-1])`
是**调用点参数**，不是状态跃迁 —— 客户端那套「状态差分探测器」**永远看不见它**
（这也是它此前整条缺失的根因）。

| 项 | 值 |
|---|---|
| 形状 | `{ player, cardId } \| null`（只保留最近一次，覆写语义）|
| 写点 | `state/reduce.ts` 的 `playCard()`（**成功才写**：`ok: false` 那条路连卡都没扣）|
| 不进指纹 | `net/protocol.ts` 的 `stateFingerprint` 是**显式字段表** ⇒ 天然排除；`use-card.test.ts` 有 4 条用例钉住（含「改它不影响校验和」）|
| 不进存档 | `loaders/savegame.ts` 与 `rules/new-game.ts` 初值 `null`；与 `lastNpcWalks` / `lastEvent` 同一类 |

#### (3) client：`cardPlaySpeech()` —— 一条**独立于状态差分**的台词通道

`speech.ts` 新增 `cardPlaySpeech(before, after)`：`lastCardPlay` 变化时，
用 `speech-bubble.ts` 的 `cardLineBubbleOf()` 造一段气泡（文本 + 语音 + 表情图），
在 `main.ts` 的 `playSoundFor` 里**先于**状态跃迁派生的台词入队（顺序与原版一致：
那句在卡片函数体内，早于效果引发的台词）。语音照旧走 `SpeechQueue` + `speechTick()`
的 `sound.play('Speaking.mkf', voice)`，无需新播放通道。

三道「不说话」的闸**照抄原版 `player_say` 开头**（`0x44ef79`/`0x44ef86`/`0x44ef93`）：
**消失中 / 夢遊 / 冬眠** ⇒ 直接不说（監獄 / 醫院 / 住宿**不**在闸内，照说）。

★ 顺带实证：`player_say` 的**第二个实参（flag）函数体里一次都没读**
（235 条指令里 `[esp+0x28]` 零命中）—— 各卡传 0 或 3 的差别**没有语义**，
复刻侧不需要建模。已写进 `rich4-spec/docs/systems/dialogue-voice.md` §二。

★ 顺带反向核：**26 / 30** 张卡读自己那一槽，没读的 4 张正是四张被动卡
（18/19/20/21，空桩），且 26 张**槽号恒 = 卡号-1**（`test_god_charm_cards.py` 的 `[M]` 段）。
