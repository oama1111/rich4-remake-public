#### (1) ✅ 投注屏 WndProc：`call()` 换成**手搓帧**，ESP 漂移消失

第 123 条定位到「`call()` 的帧与 WndProc 的帧口径差 `0x2c`」。本轮按那条路改：

```python
eval_block(0x42F7FC, 0x42F92D, regs={'esp': 0x53F000}, setup=…)
#   [ESP]      = 返回地址（哨兵）
#   [ESP+4/8/c/10] = hwnd / msg / wParam / lParam
#   停址 = `ret 0x10` **之前**（不执行那条 ret）
```

⇒ **`0x104` 的 ESP 漂移消失**，`0x401`（建屏）/`0x405`（状态置位）/`0x201`/`0x205`
与**现金闸的三条分支**都能跑完 —— 工作稿 **19/25** 通过。

**仍未通的 5 条**（状态链），症状收窄成两条（都写进工作稿，**不写成断言**）：
① `0x113` 的闸门要 `wParam == [0x46cad8]`（实测 `0/0`、`0x113/0x113`、`0x1111/0x1111`
三种组合放行），放行后崩在 `0x42fdb6`（状态 5 的公库金额绘制，本稿缺那一段的桩）；
② 状态 1→2 / 2→3 需要 `0x44ee18`（气泡）**返回 1**（原版语义 =「还有没有说话」），
改桩后仍未推进，中间还有一道未读到的判据。
⇒ 这 5 条**先不写**（写了就是「复述实现」而非真值）。

#### (2) ✅ 顺手核掉 `0x430ab5`（開獎收尾）—— 与 `drawLottery` 逐条一致

`0x430ab5` 是開獎屏收尾那一支（82 字节、1 个规则写点 `[0x499080]`），本轮与
`packages/core/src/places/lottery.ts` 的 `drawLottery` 逐条对读：

| 原版（`0x430b07` 起）| 复刻 |
|---|---|
| `for (i = 1; i < 0x24; i++)` 扫 `[0x4990b8]`；`inc byte [esp + edx + 0x7f]`（按持有者计数）| `perPlayer` 的 `Map` 累计 |
| 记下已售号码：`mov dl, al / inc dl / mov byte [esp+ebx+0x40], dl` | `sold.push(i)` |
| 四条 `cmp byte [esp+0x80..0x83], 0xa / ja` ⇒ 任一人 > **10** | `LOTTERY_RIG_THRESHOLD = 10` 的 `some(n > 10)` |
| 已售模式：`rand() % ebx`（**ebx = 已售张数**）→ `bl = [esp+edx+0x40]` | `sold[rng.next() % sold.length]` |
| 未售模式：`xor ebx,ebx / mov ebx,0x24` ⇒ `rand() % 0x24` | `rng.next() % LOTTERY_NUMBERS` |
| 中奖：`give_money(owner-1, [0x499080], 1)` → 公库清零 → `memset(0x4990b8, 0, 0x24)` | `winner = owner - 1` / `prize = pool` / `pool = 0` / `emptyLottery()` |
| **没人中 ⇒ `je 0x430afb`**：公库与号码表**原样留着** | `if (owner === 0) return unchanged(...)` |

⇒ **无偏差**。★ 注意复刻把这套计数写在 `drawLottery` 里（它由
`places/lottery-ceremony.ts` 调用），而不是直接驱动 `0x430ab5`；
两者是**等价重写**（原版那段是開獎屏 WndProc 的一支）。
