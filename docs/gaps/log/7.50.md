#### (2) 本轮修的两处

**① 新聞入狱没清"另一张"表**（`news-effects.ts` 的 `confine` 只传了 5 个参数）
⇒ 「住院中被新聞判入狱」会**同时占着医院床位**。现补 `otherOccupancy` 并写回。

**② ★★ 破产不腾床位**（`state/reduce.ts` 的 `applyBankruptcy`）

原版在清玩家结构**之前**就按**玩家号**把两张表那一格清了：
```asm
0040ce19  mov edx, [esp + 0x418]          ; player
0040ce22  mov byte [edx + 0x496b30], bl   ; 在狱表[player] = 0
0040ce28  mov byte [edx + 0x496b60], bl   ; 入院表[player] = 0
```
复刻只清玩家结构里的四个计数器（`markPlayerBankrupt`）⇒ **破产者的床位永远占着**，
監獄／醫院格会显示**幽灵占用**（4 人局里越攒越多；`anyoneConfined()` 也会被带偏）。
现补上两句（含"别人的床位不动"的回归）。

#### 诚实边界

- 本轮的普查口径是**文本级**（找 `confine(` 与字段赋值）。若某条路径**内联**了
  关押逻辑（不走 `confine`），不会出现在这张表里 —— 目前没发现，但不能证明没有。
- 「破产清床位」这条是**静态读码**（`0x40ce22`/`0x40ce28`）推出的，没有为该点
  单独做通道 2 差分（`0x40cd87` 会走 MKF，见 §7.44 的第三类限制）。
- 监狱/医院格"有人"的实际显示效果（`anyoneConfined()`）**没有**在客户端跑起来看。
