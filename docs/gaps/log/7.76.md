#### (2) 发现：复刻的股票价格会**差一跳**（T-STOCK-1）

`places/stock-market.ts` 的 `applyPriceTick` 用 JS `%`（= C fmod）算余数 ⇒ 在「`diff` 恰为
`tick` 整数倍」时与原版差一跳。实测复现率：通用（非整数）输入 **1200/1200 一致**，
「整数价 × 整数涨跌」族 **39/2800 差一跳**。**新闻 ±10% 命中的正是这一族**
（`news_dir` 把动能写成 ±10.0f），而股价长期停在 tick 整数倍上 ⇒ 实战可复现。

**未修，理由**：`fprem` 整除情形的分界不是 `k` 的简单函数；试过的启发式（|q−n| 极小且 n≥8）
只把 39 例修到 6 例且**引入新错例**（`(1,+5)`）——属于「修一半」。要一致得照抄
`fprem` 的「每轮 3 位商 + PC=53 舍入」算法。已写进 `known-deviations.md` 的 **T-STOCK-1**
并在 `applyPriceTick` 注释里留了指针与复现表；护栏就是本测试的 §E/§F。
