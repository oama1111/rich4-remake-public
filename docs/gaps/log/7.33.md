#### (2) 槽内 12 字节的布局（本轮逐条实测 `0x004246c5`）

| 偏移 | 型别 | 语义 | `@source` |
|---|---|---|---|
| `+0x00` | u8 | 類型 0=空 1=股票 2=地產/設施 3=道具 4=卡片 | `0x424725` |
| `+0x01` | u8 | 挂牌天龄（**只写不读**） | `0x42472d` |
| `+0x02` | **u16** | 物品编号 | `0x424733` |
| `+0x04` | **u32** | 標價 | `0x42473e` |
| `+0x08` | **u16** | 股數（只有類型 1） | `0x424751` |
| `+0x0a` | u8 | 類型 2：地產/設施的 `+0x18` | `0x424785` |
| `+0x0b` | u8 | 類型 2：`+0x1a`（等級） | `0x42478f` |

★ 三处易错：`+8` 是 word、`+a/+b` 是**两个 byte**（12 ≠ 3×u32）；
`+a/+b` 是**挂牌那一刻**的快照；判空只认 `+0`。
