## ★ 看到不对劲：按 **F9**，再写一句话

游戏里任何时候按 **F9**，当场存一份「问题回报」（现场快照 + 之前十来个回合的每一步 + 当时的截图 + 报错）。
开发这边拿到文件就能把你那一刻**逐步重放**出来，不用你描述怎么走到那儿的。

- 桌面版存到：`~/Library/Application Support/com.rich4.remake/reports/`
  （访达里按 `⇧⌘G` 粘贴这个路径）；网页版存到「下载」文件夹。文件名 `rich4-report-日期-时间-manual.json`。
- 存好之后左下日志栏会出一行「📝 問題回報已存：…」。
- **你只需要补一句话**：哪里不对、你觉得原版是什么样。例：「魔法屋女巫说话时嘴没动」「走到醫院后镜头没跟回来」。
  画面/动效类的问题，**先按 F9 再做别的** —— 截图截的是按键那一刻。
- 程式出错、或**电脑的回合卡住超过 1 分钟**，会**自动**存一份（文件名结尾是 `-error` / `-stall`），
  看到这类文件直接发过来就行。
- 声音类问题截图帮不上忙，请写清：哪一屏、做了什么动作、听到了什么 / 该听到什么。

开发侧重放：`node --experimental-strip-types tools/replay-report.ts <回报.json> --shot 当时.png --trace`

## 0. 准备：怎么起、怎么跳屏

- 试玩包：`dist-macos/` 里**最新那一版** zip（顶部说明见 `dist-macos/README-试玩说明.md`），
  解压后 `open "大富翁4 重制版.app"`。素材随包，不需要原版游戏目录。
- 起网页版逐屏看（开发用）：`pnpm dev`，浏览器打开后：
  - 跳过标题直接进棋盘：`?screen=game`
  - 四家全电脑自己跑：`?screen=game&humans=0&ai=4&map=0&seed=7`
  - 任意一屏都能钉住：控制台 `globalThis.__rich4.goto('assets')`（DEV 才有），
    冻结逐帧推进的屏再 `performance.now = () => 0`。
  - 大地圖 = 按 **M**；託管AI = 按 **A**。
  - 命令与坑见 [`handoff.md`](handoff.md) §2「怎么跑」。
- ⚠️ **面板隐藏时画布没有布局尺寸，点哪儿都没反应** —— 先把预览切前台再验（handoff §2）。
- ⚠️ 出厂两档设定（原版那份 `RICH4.CFG` 本身如此，**不是 bug**）：`遊戲速度 = 2`、
  `動畫過程 = 关`（影片默认不播，棋子走动与片头过场照播）。

## 4. 每屏六项的判法（勾之前先看这一行）

| 项 | 怎么算「过」 |
|---|---|
| 进得去 | 用工具列／热键／落点三种入口各进一次，都进得去；进去后**画面不是白的**（handoff §6 的教训：`blitStage()` 被跳过的屏会白画） |
| 布局 | 与上面「原版预期」逐条对：位置、字、颜色、格数、行数；**截图只用来验证，不用来取证** |
| 每颗钮可点 | 每颗都真的点一次；**按下/抬手行为可能不同**（原版不少屏是「按下记账、抬手成立」）；点完看状态有没有变 |
| 音效 | 该响的响、**不该响的不响**；注意「動畫過程」出厂是关的 |
| 语音 | 有語音的屏（角色台词/事件）听得到、不重复、不被打断 |
| 退得出 | EXIT／右键／ESC 三种退出方式按原版来；退完棋盘状态正常（没有卡在模态） |

## 5. 30 分钟怎么分配（建议）

| 时间 | 做什么 |
|---|---|
| 0–3 min | 起包、过标题、进選角色／選地圖，照 §1 的 1–2 步勾 |
| 3–10 min | 开一局（四家全电脑或 1 人 3 电脑都行），照 §1 的 3–7 步走完开局→买地→路过费→道具/卡片 |
| 10–18 min | 银行 → 股市 → 百貨公司 → 公佈欄（照 §1 的 8–10 步） |
| 18–24 min | 月结 → 破产 → 终局（§1 的 11–13 步；破产可以靠反复缴过路费/贷款硬造） |
| 24–30 min | 回工具列 11 颗按钮与 §3 里刚才没进过的屏，逐屏勾六项 |
