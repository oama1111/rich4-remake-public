#### (2) ★★ 真 bug A：`streetTollOf` 漏乘物价指数 ⇒ **機器娃娃 / 路障 / 烏龜卡 三处 AI 判定在 pi>1 后整体偏移**

原版 `0x419744`（某地主某條街的住宅过路费总和）的收尾是：

```asm
004197d8  mov  ecx, dword ptr [0x4990e8]   ; 物價指數
004197de  mov  eax, edi                    ; Σ 各级租金
004197e0  imul eax, ecx                    ; ★ 返回值**含**物价指数
```

而三处调用方的门槛是 `3000×pi` / `6000×pi` / `1000×pi` / `10000×pi` ⇒
**住宅那一路的 pi 两边约掉，实际判据是常量 3000 / 6000 / 1000 / 10000**。
复刻的 `ai/card-policy.ts` 的 `streetTollOf` **没有乘 pi**，门槛却照乘
（`tool-policy.ts:206`、`:264`、`card-policy.ts:874`、`:914`+`:945`）⇒
**物价指数升到 2 以后，这三支 AI 的判断整体偏向一个方向**
（差分实证：pi=2、对手街价和 1500 ⇒ 原版作废、旧复刻**不作废**）。

**修法**：`streetTollOf` 增加 `priceIndex` 参数并乘上（四个调用点同步传 `pi`）。
差分证据：`test_turtle_card_ai.py` 的 DISCREPANCY #1；
TS 侧新增 2 例（pi=2 与 pi=1 同结论，排除"只是把门槛改了"），
另在 §7.139(3) 的 `feidan`/路障/機器娃娃侧共用**同一个** `streetTollOf`，一处修三处受益。

#### (5) ★★ 位置不变量漏了两个窗口（**测试**修，不是规则修）—— 顺带证明规则是忠实的

`chashui` 修好之后，`full-game.test.ts` 的「坐标不变量」在**种子 1 第 8543 步**报红
（玩家 3 坐标 = 医院大樓 (319,990)、`nodeId` = 醫院格、**四个阻碍计数全 0**）。逐层追下去：

```
魔法屋 idx10「住院檢查三天」 → sendToConfinement（inHospital=3、node=醫院格、x/y=景观坐标）
      ↓ 同一回合的命運事件「被綁架」→ fortune-effects.ts:415-428
   inHospital 被清 0、disappearing=3，**全程不动 x/y**（原版 `0x40d761` 也只清计数）
      ↓ disappearing 到期释放（0x40d4e5）
   disappearing 清 0，仍然**不写 x/y**（原版 `0x40d4e5` 只 `or node[+0x24]` 登记到场；`0x40d375` 也只是把旧 x/y 传给飞走动画 `0x41d476`）
   ⇒ 零标志 + 医院景观坐标 + nodeId=醫院格
```

⇒ **原版就是这个状态**（消失期间玩家不上屏，坐标无意义），复刻忠实。是**不变量漏窗**：

1. 把 `disappearing !== 0` 加入合法窗口（期间贴图坐标可以是景观/設施坐标）；
2. 追加**精确**的第六窗：仅在**脚下就是監獄/醫院格**时，允许贴图坐标 —— 因为能造出
   "零标志 + 景观坐标"的路径**只有关押传送**，而它必把 `nodeId` 设成该格。
   **不变量没有被放松**：别处仍按节点坐标严格判，集合外的乱值照样红。

#### (6) 已确认但**有意未改**的口径差异（如实登记）

- **停留卡 `level ≥ 2` 自用支：原版返回 1 却*不写* `[0x48be58]`**（`0x41fc1d eb d9`
  跳到 `0x41fbf8`，正好跳过 `0x41fbf3` 的存值）⇒ 原版 AI 拿到**上一次判定的残留目标**。
  复刻返回 `SELF`（= 对自己），即**实现了原版的意图**而非它的缺陷。
  复现它需要在 AI 层引入一个跨决策的"参数全局"，属架构级改动，且是在复刻一个**未初始化/残留读**——
  与 **D-LEGACY-2**（未初始化栈槽 → 复刻不做）同族。**记为待决**，本轮不改。
- **并列次序**：原版可见表按**旋转栅格行序**（`0x40a050` + 每图旋转矩阵 `0x474910`）收集，
  复刻按 `(y,x)` 排（`tool-policy.ts:143`）⇒ 两个**同等级**候选时会选到不同格。
  D-005 原文说"视野差异不影响数值"，**对并列这一条不成立**，已在 `test_tool_transport_ai.py` 记录。
- **`isAlive` 是 `(whoPlays & 3) != 0`，原版是整字节 `!= 0`**（`0x40d2f2`/`0x40d338`）。
  只在"低 2 位为 0 而高标志位非 0"时不同 —— 该状态**可达性无法判定**，登记口径差异。
- **`0x4216ab` 的「不是我的」出口返回调用方的 `edx`**（`0x421714 mov eax,edx`，
  该路径无 `xor edx,edx`）—— 原版编译产物怪癖，复刻无从复现也无需复现，已由
  `test_missile_target_ai.py` 的 [A9] 钉住原版真值。
- **查稅卡门槛是 32 位有符号乘法**（`pi ≥ 42950` 时 `50000×pi` 回绕为负 ⇒ 门槛无条件通过）；
  复刻用 JS double。pi 的可达上限取决于对局资产 ⇒ **无法判定**，不据此判错。
