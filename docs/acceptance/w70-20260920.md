### 4.2 白名单里的 7 个 `.mkf` 能取

```
$ curl -o /dev/null -w '%{http_code} %{size_download}\n' http://127.0.0.1:8787/assets/game/Data.mkf
200 54208369
```

（`Data/Panel/map/jump/help/Speaking/Effect` 七个逐条在 `http-server.test.ts` 里钉着；
配乐另钉 `midi01.mid` / `midi14-1.mid` 与**大写写法** `MIDI01.MID`——磁盘上是小写，
`main.ts:3339` 先试原名再试小写，两边都要认。）

### 4.3 目录穿越 / 绝对路径注入

```
$ curl --path-as-is -i 'http://127.0.0.1:8787/assets/game/../package.json'
HTTP/1.1 400 Bad Request
X-Robots-Tag: noindex, nofollow, noarchive
X-Content-Type-Options: nosniff

$ curl -o /dev/null -w '%{http_code}\n' 'http://127.0.0.1:8787/assets/game/%2e%2e%2fpackage.json'
400
$ curl -o /dev/null -w '%{http_code}\n' 'http://127.0.0.1:8787/assets/game//etc/passwd'
400
```

（`curl` **不加** `--path-as-is` 时自己会把 `..` 归一掉、拿到的是 404 —— 非 200 同样成立，
但那不是服务器的判据；上表那条才是。）

### 4.4 `/robots.txt` 与三个安全头

```
$ curl -i http://127.0.0.1:8787/robots.txt
HTTP/1.1 200 OK
X-Robots-Tag: noindex, nofollow, noarchive
X-Content-Type-Options: nosniff
Referrer-Policy: no-referrer
Content-Type: text/plain; charset=utf-8
Cache-Control: no-cache
Content-Length: 26

User-agent: *
Disallow: /
```

正文 26 字节与 `ROBOTS_TXT` **逐字相等**；三个头在 **200 / 400 / 403 / 404 / 405**
上都由 `send()` 统一加上（`http-server.test.ts` 的「200 / 404 / 403 / 400 上都带着三个安全头」
那条逐头逐值钉着）。

### 4.5 预压缩

`Data.mkf.br` 与 `Data.mkf.gz` 放进同一个目录后：

| 请求头 | 回哪一份 | `Content-Encoding` | `Vary` | `Content-Length` |
|---|---|---|---|---|
| `Accept-Encoding: br` | `Data.mkf.br` | `br` | `Accept-Encoding` | **压缩后**的长度 |
| `Accept-Encoding: gzip, deflate` | `Data.mkf.gz` | `gzip` | `Accept-Encoding` | 压缩后的长度 |
| 不带 | `Data.mkf` | 无 | 无 | 原文件长度 |
