### 浏览器目视验证（**必须做**，单测证明不了画不对）

`.claude/launch.json` 已经配好了（工作区根目录那份，端口 5173）。
用 Browser 面板起 dev server，然后：

- **跳过标题直接进游戏**：`?screen=game`
- **四家全电脑自己跑**（看 AI 买地盖房）：`?screen=game&humans=0&ai=4&map=0&seed=7`
- **看整张地图**：按 **M**（大地圖）。`DEFAULT_BINDINGS[17] = 0x4d`
- **开託管AI 屏**：按 **A**（`DEFAULT_BINDINGS[20] = 0x41`）
- **放大看细节**：把视口设成 `1320×1000`（stage 会按 2 倍渲染）；**看完记得复位成 `desktop`**

⚠️ **合成事件要派在 `canvas` 上并 `bubbles: true`**，别派在 `window` 上 ——
`window` 上派发的那条路在这个环境里到不了页面自己的监听器；画布上派发能冒泡上去。
按键事件还要带 **`keyCode`**（`vkOf(e)` 优先读 VK 码）：
```js
const c = document.querySelector('canvas');
c.dispatchEvent(new KeyboardEvent('keydown', { code:'KeyM', key:'m', keyCode:0x4d, which:0x4d, bubbles:true }))
```

⚠️ **坐标要按「设备像素」算**：`eventToStage()` 用的是 `canvas.width/height`
（= CSS 尺寸 × dpr）配 `stageMetrics()`。窗口是**整数倍放大且居中**的，
按 CSS 尺寸算 scale 会差一倍。

★ **任意一屏都能钉在屏上截图**（`?screen=` 只认 `game`）：
```js
globalThis.__rich4.goto('assets');       // DEV 下才有的调试出口（main.ts 末尾）
```

## 5. 反汇编速查（干这活的主要工具）

```bash
python3 tools/disasm.py va 0x004090fc 60      # 反汇编
python3 tools/disasm.py dump 0x475218 24 1    # 原样打印数据表（1/2/4 字节）
python3 tools/disasm.py table 0x44faa0 7      # 函数指针表
python3 tools/disasm.py callers 0x40df69      # 谁调用了这个函数
python3 tools/disasm.py xref 0x496b84         # 谁碰了这个全局
python3 tools/disasm.py find <hex>            # 搜字节
```

**更快的办法**：`rich4-re/asm/*.asm` 是全量反汇编**文本**（`rich4.asm` 有 5.5 万行），
`grep` 一个全局地址比逐段线性反汇编快得多。我最后就是靠
`grep -n "ref_0048aea8" *.asm` 一步找到 logo 图集的加载点的。

### 我这轮靠汇编解出来的东西（接手时直接可用）

| 是什么 | 结论 |
|---|---|
| `draw(串, x, y, flag)` 的 **flag** | **对齐方式**，7 路跳表在 `0x44faa0`：`0/>7`=左上、`1`=右上、**`2·3·4`=正中**、`5`=左+中、`6`=右+中、`7`=中+下。**`x`/`y` 是文字块的中心**（0 除外） |
| 日历各文字字号 | 日号 `0x3c=60`、年 `0x18=24`、月 `0x1c=28`、星期 `0x10=16`；年 flag 0（左上）、月/日 flag 2（正中） |
| 月曆折行 | `x0 + pitch×(cols−1)`（**不是** ×cols）；`0x260=608` → 側欄局部 168，两头对得上 |
| 建筑落在哪 | **地块记录自己的 x/y**（`0x498e84` = `hlands`，`add ebp,0x34` 逐项）；**不是**节点坐标 |
| 空地 logo | `map.mkf` **资源 25**，图号 = **角色号**（`player+0x13`）。加载点 `rich4_load_map.asm:477`（`push 0x19`） |
| 归属圈线的颜色 | 建筑精灵的**调色板索引 255** 是可换色槽；`0x0040987d` 把 `player[owner-1].+0x04`（角色色）写进 `sheet+0x1fe`（= 255×2） |
| 玩家结构 | `docs/player-struct.md`（基址 `0x496b68`，步长 `0x68`）；`+0x04` = 角色专属色、`+0x13` = character、`+0x1a` = 等级、`+0x1b` = 朝向、+0x19 = owner |
| `land.h` | `int16_t x,y` 在 0x00/0x02 ✓（我们的 loader 偏移是对的） |
| 小地图底图 | **`map.mkf` 资源 `(地图号 + 0x10)` 图 0**（200×200 预渲染成品，图 1 = 独立窗口的 400×400）。`_rich4_load_map` 载入（VA 0x00407fc0）。**不是**现缩 `.gnd` |
| 小地图比例 | 世界 → 局部：`(世界 × 89) >> 10`；反向：`局部 × 93/8`（**两者不互逆，差 1%**，原版如此）|
| 镜头中心 | `[0x48be1c]`/`[0x48be20]`，夹在 `[220, 2084]` = `[220, 2304−220]`；`[0x48be18]` = 「有落点」|
| 小地图箭头 | 局部 `x∈[3,53]`、`y∈[3,28]`，每颗宽 25；图号常态 **20/21**、高亮 **18/19**（`Data.mkf` 517）|
| 侧栏三态的 y | `0x4752aa` = `[0, 280, 80]`：日曆态 0（不由画小地图那支管）、小地图态 **280**、交替态 **80** |
