## 1. 纯函数 `roomToasts(before, after, strikes?)`

比较前后两份 `RoomInfo`，按**座位**比：

| 变化 | 说哪句 |
|---|---|
| 之前没这号人 / 原本是电脑，现在是人 | `{名字} 加入了房間` |
| `connected` true → false | `{名字} 離線了，30 秒後由電腦代打` |
| `connected` false → true | `{名字} 回來了` |
| `autopilot` 非 `'idle'` → `'idle'`（**第一次**） | `{名字} 超時，這一回合由電腦代打` |
| 同上（**连续第二次**） | `{名字} 連續超時，已交給電腦託管（點一下畫面即可收回）` |
| 空座补电脑 / 什么都没变 | **不说** |

★ 任务书写的是 `roomToasts(before, after): string[]`；这里返回 `{ seat, text }[]` ——
**「连续超时那条只发给其他人」需要知道说的是谁**，纯字符串表达不了。判据本身仍是纯函数，13 条单测钉着。

### 「连续两次」怎么算出来的

`SeatInfo.autopilot` 只有 `'offline' | 'idle'` 两个值，**看不出这是第几次**。
客户端按座位记一本与服务器 `strikes` **同一条规则**的账：

- `非 idle → idle` ⇒ **+1**；
- **自动归还**（第一次超时后回合结束，`idle → 非 idle`）⇒ **不清零** ——
  服务器那边这时 `strikes` 也还是 1；
- 该座位**自己派了一条 action** ⇒ 清零（`NetToasts.noteIntent`，对应 `hub.ts` `#submit` 里那一句）。

★ 另有一条常驻横幅的判据 `selfAutopilot(info, mySeat)`：本机座位 `autopilot === 'idle'` 才算，
掉线代打（`'offline'`）**不算**。

## 2. 浏览器验收（生产构建 + 部署素材，三个标签页）

在 A 的页面里装一个 `MutationObserver` 记下**所有出现过**的提示（它们 4 秒就自己收了，
不记下来读不到）：

```
B 关掉后:      ["B 離線了，30 秒後由電腦代打"]
B 回来之后:    ["B 離線了，30 秒後由電腦代打","B 回來了"]
C 进来之后:    ["B 離線了，30 秒後由電腦代打","B 回來了","C 加入了房間"]
```

常驻横幅：`#autopilotbanner` 在（正文「你已被託管，點一下畫面收回」）、此刻 `hidden === true`
（没人被託管）—— 它的显隐由上面那条 `selfAutopilot()` 决定。
