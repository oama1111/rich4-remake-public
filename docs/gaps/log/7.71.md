★ **测试台又踩一个坑（值得记）**：公共卡尾 `0x4440e3` 是**共享尾声**
（`mov eax,edi / pop ebp / pop edi / pop esi / pop ebx / ret`），
第一版把它打成 `ret` 想"让 `jmp` 出去等于返回"，结果 **`ret` 把栈上保存的 ebp 当返回地址**
⇒ 跳到栈里崩（`Invalid memory read @0x53fef8`）。正确做法是**不打桩**，让它自然跑完。
