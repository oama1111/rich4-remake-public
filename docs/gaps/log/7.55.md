#### (4) 顺手捞到一条**通用结构**：MKF 记录表

复核第 6/7 条时把「图号 → 地址」的换算逼了出来，它是全工程通用的：

```
表基址 [0x48c41c]（Panel#25）/ [0x48c270]（Panel#9）/ [0x48c398]（魔法屋）
  = read_mkf(...) 的返回值
第 k 项的地址 = 表基址 + 0xc + 12×k        ← ★ 12 字节表头
项内：+0 = 像素指针(dword)  +2 = 高度(word)  +6 = y 偏移(word)
```

已写进 `rich4-spec/docs/systems/render-api.md`「链路 1之二」。
★ 这条一立，两条注释错误立刻显形：`+0x18` 是**图 1**（不是图 2/7）、
`+0xf0` 是**图 19**（不是图 29）。
