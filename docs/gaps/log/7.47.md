### 7.47 ★ 第 66 条（本轮）：把上一轮的**猜测**查实（并推翻），再把工作单的"表现层"判据修准

上一轮在 §7.46(3) 里写「`0x40a4e1` 很可能有规则作用」—— **那是猜测**。本轮读完了它，
结论相反：**它是彻头彻尾的绘制**。同时发现工作单的"表现层"判据有两处不准。

#### (1) `0x40a4e1` 结案：小地图标记，纯绘制（A 级）

```asm
0040a4ed  ecx = [0x48badc] + 0xc + idx*0xc     ; 精灵记录
0040a503  edx = [0x48bad0] + 0xc + idx*0xc     ; 落点记录
0040a50f  call 0x456280                        ; → sub_00456280 → **blitRect_inner**
; 再遍历整张地块表（0x498e84 / 0x498e98）：
0040a5cd  push [ebp + 0x496b6c]                ; ebp=(owner-1)*0x68 ⇒ **player+0x04 = 颜色**
0040a601  call 0x456384                        ; 又一层 blit 包装
```

⇒ 只读颜色、只走 blit、**不写任何规则状态**。复刻把它当表现层**是对的**
（`cards/monster.ts` 原先那句注释没错，是**我上一轮的猜测**错了，已在 §7.46 划掉）。

★ 顺带**结掉 PRD 的开放项 U7**：`0x48bad0` 与 `0x48badc` 读同一份 MKF 资源两遍
**不是冗余** —— `0x48badc` 当**精灵**（`blitRect_inner` 读它的 `+0/+2/+8`），
`0x48bad0` 当**落点**。⇒ "缩略图"这一用途从"弱证据"升为 **A 级**（由调用链证实）。
已写进 `rich4-spec/docs/systems/map-format.md`。

#### (2) 工作单的"表现层"判据修了两处（都是我自己写的）

| # | 问题 | 后果 | 修法 |
|---|---|---|---|
| 4 | 判据只看**直接**被调函数名 | `0x40a4e1` 只调 `sub_00456280`（名字看不出来）⇒ 漏判 | 追 **2 层** callee 闭包 |
| 5 | 我第一版闭包**按名字**查 callee 入口（`by_va.get(c)`，键是 VA）⇒ 永远查不到 | 闭包形同虚设 | 改按 **VA** 取 |
| 6 | 修好闭包后**一刀切**排除 ⇒ 把 `0x004379c9`（银行结息：**会弹消息框**但写玩家/地块字段）**藏了起来** | 真规则从工作单消失 | 加 `impact() == 0` 这道闸：**只有"只画不写规则"才排除** |

效果：候选 **175 个 / 70,324 B → 166 个 / 69,136 B**，
被剔掉的 9 个都是纯绘制，而 `0x4379c9` 这类"规则+弹窗"的**留了下来**。

> ★ 另一条写进工具 docstring 的认识：**WndProc 不是天生不可测** —— 它靠消息号分发，
> `call(va, [hwnd, msg, wparam, lparam])` 就能驱动**单条消息分支**
> （如 `0x42f7fc` 投注屏的 `WM_TIMER`/`0x401`）。故工具只在"它不写规则状态"时才排除。

#### (3) 顺手探了 `0x40d761`（清两张占用表），撞上第三类限制

它按 `+0x34`/`+0x35` 分两支，各清一张 per-player 占用表
（`0x496b30+player` / `0x496b60+player`），**无条件**把 `+0x32` 那个 dword 清零；
两支都会 `call 0x40bf93(player, which)` —— 而 `0x40bf93` 走到 **`mkf_read_resource`**，
纯仿真 `UC_ERR_READ_UNMAPPED @0x450471`。⇒ 它的差分测试需要给 `0x40bf93` 打桩
（下一轮；本轮只把"记录改动"这一半探清）。

#### 诚实边界

- 本轮的产出偏**工具与方法**，不是新规则：`0x40a4e1` 的结论是"**不需要**实现"。
- `0x40d761` 只探到"调用 `0x40bf93` 之前"的状态；`0x40bf93` 与两张占用表的
  释放规则**未验**。
- 工作单的 WndProc/表现层判据仍是**启发式**（消息号 + callee 闭包 + impact），
  自绘型或"规则藏在绘制函数里"的仍可能漏。
