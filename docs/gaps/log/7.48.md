### 7.48 ★ 第 67 条（本轮）：`0x40d761` 补差分（15/15），顺带揪出**命運路径**两处真缺口

按上一轮留下的口子取 `0x0040d761`（80 字节）。它小，但一验就发现**两条调用链都在漏**。

#### (1) 差分：`tests/test_confinement_release.py` **15/15**

```asm
0040d769  if ([player+0x34] == 0) goto 看医院     ; inPrison
0040d774      [player + 0x496b30] = 0            ; 监狱占用表（**按玩家号**索引！）
0040d77d      call 0x40bf93(player, 1)           ; 换图标（MKF，纯表现）
0040d78b  if ([player+0x35] == 0) goto 收尾        ; inHospital
0040d793      [player + 0x496b60] = 0            ; 医院占用表
0040d79c      call 0x40bf93(player, 0)
0040d7a9  dword [player + 0x496b9a] = 0          ; ★ 四个计数器一起清（含刚做判据的 +0x34/+0x35）
```
验到：两道闸各管一张表；**按玩家号**索引；dword 清零会抹掉判据字节；幂等；只动被调玩家。

⚠️ `0x40bf93`（168 字节）打桩成 `ret`：它是 **MKF 图标装载**
（`0x40bff7 call mkf_read_resource`，写每玩家表 `0x498ea0..a3` / `0x498eb8`）——
第三类纯仿真限制。被验的是它**之前**的占用表与计数器改动。

**四个调用点**（自扫）：`0x40d3ad`（**消失**首次）、`0x41a7c5`（归属未定，已列未决）、
`0x43d5e7`（入狱首次）、`0x43ec93`（入院首次）。

#### (2) ★★ 真缺口一：命運「住院」把病人记进了**监狱**表

`reduce.ts` 给命運函数传占用表时**无条件传 `prisonOccupancy`**
（注释还写着"按事件实际走向取对应的占用表"，但代码没做到），
而 `fortune-effects.ts` 也只有一个 `occupancy`；收尾又把结果写回 `prisonOccupancy`。
⇒ **住院事件把床位记进监狱表**，医院表永远空着（医院屏永远显示没人、床位统计全错）。

> 这与 `news-effects.ts` **2026-09-17 修过的是同一个错**（那边叫"单一 `occupancy`"），
> 當時只修了新闻那条路，**命運那条漏了**。

**修法**（照抄新闻那边的形状）：ctx/result 各拆成
`prisonOccupancy` + `hospitalOccupancy` 两张；坐牢/住院按 `kind` 取表，
并把**另一张**交给 `confine(..., otherOccupancy)` 去清（= 原版 `0x40d761` 的"清另一张"）。

#### (3) ★★ 真缺口二：「消失」没有清掉别的关押状态

原版首次「消失」在 `0x40d375` 里先 `call 0x40d761`（`0x40d3ad`，在
`cmp byte [+0x33],0 / jne 出去` 之后），也就是**和入狱/入院首次同一段收尾**：
清监狱/医院占用表对应格 + 四个计数器一起清。复刻只写 `disappearing` ⇒
**「住院中被綁架」会同时留在医院**（`inHospital` 不清、床位不清，那张床再也放不出来）。

**修法**：消失支按同样的两道闸清占用表 + 清 `inHotel/inPrison/inHospital`，再写 `disappearing`。

#### (4) 回归用例（+6）

`packages/core/src/events/fortune-effects.test.ts`：
住院写医院表 / 坐牢写监狱表 / 首次关押清另一张 / 住院中被綁架释放床位 /
坐牢中被綁架释放床位 / 本来没被关时两张表都不动。

#### 诚实边界

- `0x40bf93`（图标装载）与 `0x40b8d8`（它在 `test byte [+0x34],0x30` 时调）**未验**；
  前者是表现层，后者未定。
- 四个调用点里 `0x41a7c5` 的**业务归属未定**（只知在 `update_hostility` 之后对当前玩家调用）。
- 差分是单调 `0x40d761`；四条调用链**没有**整条跑过。
